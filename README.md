# rupipe — русская 5.1 из стерео-закадра

*Builds a Russian E-AC3 5.1 track from a 5.1 original and a stereo Russian voice-over in the same MKV: the voice is extracted by subtracting the aligned original and placed into the original's centre channel. Documentation is in Russian; the AI-agent skill in `skill/` is in English.*

В релизах часто лежит хороший оригинальный звук 5.1 (E-AC3, нередко с Atmos) и русский закадр только в стерео. Слушать такой закадр на 5.1-системе обидно: эффекты, музыка и пространство сведены в два канала. rupipe берёт оба потока из одного MKV, вычитает выровненный оригинал из русской стереодорожки — остаётся чистый русский голос — и кладёт этот голос в центральный канал оригинальной 5.1. Музыка, эффекты и тылы остаются оригинальными.

Результат — новая дорожка E-AC3 5.1 (1024 кбит/с), добавленная первой и по умолчанию в копию MKV. Исходный файл и все его дорожки не меняются.

Почему 1024 кбит/с, если у оригинала обычно 576–768: оригинал уже сжат, а мы сжимаем его второй раз, кодировщиком ffmpeg, который проще фирменного. На битрейте исходника вторая волна потерь заметна на верхах (на 8–14 кГц искажения всего на ~11 дБ тише сигнала), на 1024k — на ~28 дБ тише, то есть практически незаметна. Выше 1024k не поднимаемся ради совместимости с плеерами и ресиверами. Цена — около 0,1 ГБ на час видео.

- Работает с закадром (русский голос поверх слышимого английского). Полный дубляж пока не поддерживается.
- Оригинал должен быть 5.1 (7.1 пока не поддерживается; Atmos-объекты отбрасываются, остаётся 5.1).
- Нейросети и видеокарта не нужны: только ffmpeg, MKVToolNix и Python. Серия обрабатывается за несколько минут на обычном процессоре.

> **Важно.** Инструмент предназначен для личного использования с видео, на которое у вас есть права. Русская озвучка — труд студии, оригинальный звук — труд правообладателя; не распространяйте полученные дорожки и файлы без их разрешения.

## Установка

Нужны Python 3.10+, [ffmpeg](https://ffmpeg.org/download.html) (полная сборка, с кодировщиком E-AC3) и [MKVToolNix](https://mkvtoolnix.download/downloads.html). Подробно для Windows, Linux и macOS — [skill/references/setup.md](skill/references/setup.md).

С [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run pipeline doctor
```

Или через pip:

```bash
python -m venv .venv
.venv/bin/pip install -e .          # Windows: .venv\Scripts\pip install -e .
.venv/bin/pipeline doctor
```

`doctor` проверяет Python, пакеты, ffmpeg, ffprobe, mkvmerge и место на диске и пишет, чего не хватает. Если программы стоят не в PATH, пропишите пути в `config.local.yaml` рядом с `config.yaml`:

```yaml
tools:
  ffmpeg: C:/ffmpeg/bin/ffmpeg.exe
  ffprobe: C:/ffmpeg/bin/ffprobe.exe
  mkvmerge: C:/Program Files/MKVToolNix/mkvmerge.exe
```

## Как пользоваться

Ниже `pipeline` — это `uv run pipeline` (или `pipeline` из venv).

**1. План.** Все аудиодорожки каждого файла и что будет выбрано; ничего не обрабатывается:

```bash
pipeline plan "/путь/к/сезону"
```

**Дорожки не угадываются.** Номера, порядок, названия и даже метки языка дорожек в релизах бывают какими угодно и меняются от серии к серии. Если кандидатов несколько, программа показывает их и ждёт выбора:

- `--russian "<часть названия>"` или `--russian <номер>` — для всех файлов (номер — как в `plan`). Для сезона удобнее часть названия: номера плавают, названия обычно нет.
- `--track-for "E05=3"` — другой выбор для файлов, в имени которых есть `E05` (можно несколько; `--track-for "E05=original:2"` — для оригинала).
- `--original ...` — если оригинал определился неверно.

**2. Пробная серия** и фрагменты для прослушивания:

```bash
pipeline run "/путь/к/сезону/S01E01.mkv" --russian "<часть названия>"
pipeline fragments "/путь/к/сезону/S01E01.mkv" --count 3
```

`fragments` нарезает до четырёх полутораминутных сцен (диалог, громкая сцена, речь поверх музыки, тихий разговор) с новой дорожкой, исходной русской и оригиналом — удобно сравнивать.

**3. Весь сезон:**

```bash
pipeline run "/путь/к/сезону" --russian "<часть названия>"
```

Сначала печатается план; если хоть где-то выбор неоднозначен, ничего не обрабатывается. Прерванная работа продолжается с места остановки. В конце — `SUMMARY` по каждой серии; что значат цифры — [skill/references/results.md](skill/references/results.md).

Результат: `rupipe-out/<имя>.rus51.mkv` рядом с исходными файлами (или в папке из `--out <папка>`, указанной перед командой). Временные файлы — в `rupipe-out/work` (около 8 ГБ на час видео), после работы их можно удалить.

## Громкость голоса

Студии сводят закадр очень по-разному, а миксы бывают плотными и разреженными, поэтому фиксированная громкость не годится. rupipe сам подбирает самый тихий уровень голоса, при котором русская речь слышна поверх всего остального в заданной доле звучания — `mix.target_audible` в `config.yaml` (0,89, подобрано на слух). Если голос кажется громким — уменьшите, тихим — увеличьте; пересобрать только сведение быстро: `pipeline run ... --from mix`. Варианты для сравнения нескольких уровней в одном файле — в [skill/references/results.md](skill/references/results.md).

## С ИИ-агентом

В `skill/` лежит Agent Skill (формат [agentskills.io](https://agentskills.io): Claude Code, Codex, Cursor и другие). Агент сам проверит окружение, покажет дорожки, спросит, какую озвучку брать, соберёт пробную серию и сезон и отчитается. Собрать папку и архив скилла: `uv run python tools/build_skill.py`.
