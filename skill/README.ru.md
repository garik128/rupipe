# russian-voiceover-51 — русская 5.1 из стерео-закадра

Это навык (skill) для ИИ-агента. Он делает русскую дорожку E-AC3 5.1 из английского 5.1-оригинала и русского стерео-закадра, которые лежат в одном MKV. Русский голос выделяется из стерео-закадра и ставится в центральный канал оригинала; музыка, эффекты и тылы остаются оригинальными. Новая дорожка добавляется первой и по умолчанию в копию файла; исходный файл и его дорожки не трогаются.

## Как подключить

Вариант 1 — агент поддерживает скиллы (Claude Code, Codex, Cursor и другие с форматом Agent Skills): положите папку `russian-voiceover-51` туда, где агент ищет скиллы. Для Claude Code это `~/.claude/skills/` (в Windows — `C:\Users\<имя>\.claude\skills\`). Перезапустите агента.

Вариант 2 — любой другой агент: распакуйте папку куда угодно и напишите агенту: «Прочитай <путь>/russian-voiceover-51/SKILL.md и действуй по нему».

## Что понадобится на компьютере

Python 3.10+, ffmpeg (полная сборка), MKVToolNix, место на диске (около 8 ГБ временных файлов на час видео). Агент сам проверит всё командой `doctor` и скажет, чего не хватает; ставить программы он будет только с вашего разрешения.

## Как пользоваться

Просто попросите агента, например: «Сделай русскую 5.1 для сезона в папке D:\Serials\Show\Season 1». Агент:

1. покажет все дорожки в сериях и спросит, какой закадр брать — номера и названия дорожек в релизах бывают какими угодно, поэтому он не угадывает;
2. соберёт первую серию и нарежет 3–4 полутораминутных фрагмента — послушайте их;
3. по вашему «ок» соберёт весь сезон и покажет сводку по каждой серии.

Готовые файлы появятся в папке `rupipe-out` рядом с сериями (`<имя>.rus51.mkv`). Подпапку `rupipe-out/work` после работы можно удалить.

Если голос кажется громким или тихим — скажите агенту, громкость подстраивается одним параметром.
